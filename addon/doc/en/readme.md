# Global Sonic Pitch

Global Sonic Pitch lets you lower or raise the pitch of NVDA speech using the
Sonic audio library. It adds a separate **Sonic pitch** setting, independent
of the synthesizer's own **Pitch** control. You can adjust the sound of a
voice without changing the configured speech rate.

The add-on processes speech audio produced by a supported synthesizer. You
continue using your existing synthesizer and voice. Processing is disabled
by default.

## Requirements and compatibility

The current compatibility declaration is NVDA 2025.1 or later, last tested with
NVDA 2026.1.1. This declaration does not confirm compatibility with future NVDA
versions. The add-on includes Sonic libraries for 32-bit and 64-bit NVDA.

Supported output includes eSpeak NG, OneCore, RHVoice and 64-bit SAPI5 when
speech passes through NVDA's supported audio output. Standard 32-bit SAPI5
and SAPI4 on 64-bit NVDA are also supported. **SAPI4 requires NVDA's WASAPI
audio output; the older SAPI4 audio output is not processed.**

Other synthesizers may work if they use compatible NVDA speech output.

If you use a hardware speech synthesizer, Sonic pitch cannot process its speech
because the sound is generated by the device itself.

The add-on does not change other applications' audio or NVDA's non-speech
sounds. It does not register additional SAPI voices.

## Installation

Install **Global Sonic Pitch** from NVDA's Add-on Store. Alternatively,
download the versioned `.nvda-addon` file from the
[project's releases](https://github.com/djgraco/sonicpitch/releases), then
use NVDA's option to install an add-on from a file. Restart NVDA when prompted.

## First use

1. Open NVDA Settings and select **Global Sonic Pitch**.
2. Select **Enable global Sonic pitch**.
3. Choose **OK** or **Apply** to save the change.
4. Open **Voice** settings and find **Sonic pitch**. You can also select it
   in the synth settings ring.
5. Lower the value to lower the voice, or raise it to raise the voice.

**50 is neutral:** no additional pitch change is applied. The control uses
values from 0 to 100; these numbers are not semitones or a percentage change
in frequency. Start with a small adjustment and listen to the result.

When processing is disabled, **Sonic pitch** disappears from Voice settings
and the synth settings ring. Saved values are retained.

## Sonic pitch and the synthesizer's Pitch setting

The normal **Pitch** control changes the synthesizer's own pitch parameter.
**Sonic pitch** changes the audio produced by the synthesizer. The audible
result therefore depends on both settings. You can leave the synthesizer's
Pitch at your preferred value and use Sonic pitch for an additional adjustment.

The neutral value of 50 described here applies to **Sonic pitch**. It does
not define a universal default for every synthesizer's native Pitch control.

## Add-on settings

Open the **Global Sonic Pitch** category in NVDA Settings to configure:

- **Enable global Sonic pitch:** turns the add-on's speech processing on or off.
- **Increase Sonic pitch range to 20 semitones:** changes the range from
  −6 to +6 semitones to −20 to +20 semitones. It is disabled by default.
- **Use better-quality Sonic processing:** selects Sonic's higher-quality
  mode. It may improve some voices but use more processing power. The fast
  mode is the default. This option does not change the pitch range.
- **Enable debug logging:** adds diagnostic information to the NVDA log.
- **Support the author:** opens the author's voluntary support page.

The pitch value itself is adjusted in Voice settings, the synth settings
ring or using an assigned gesture, rather than in the add-on's settings panel.
Use **OK** or **Apply** to save changes to the add-on settings.

### Pitch ranges

| Sonic pitch | Standard range | Extended range |
| --- | --- | --- |
| 0 | −6 semitones | −20 semitones |
| 50 | No pitch change | No pitch change |
| 100 | +6 semitones | +20 semitones |

**Changing the range changes the effect of saved values other than 50.**
The add-on does not convert existing values to preserve their previous pitch.
For example, 75 means +3 semitones in the standard range and +10 in the
extended range. Larger changes may produce audible processing artifacts.

## Saved values and previewing changes

Values are saved separately for each synthesizer and voice. If the
synthesizer supports voice variants, a variant can also have its own value.
Returning to a voice or variant restores its saved value. New voices
normally start at 50; older saved configurations may supply an existing value.

Changes in Voice settings are previewed. **OK** or **Apply** saves them;
**Cancel** or **Escape** discards changes since the last save in that dialog.
Changes made through the synth settings ring or assigned gestures are saved
immediately. During speech, a pitch or quality change may take effect at the
next safe speech boundary.

## Input gestures

In NVDA's **Input Gestures** dialog, open the **Global Sonic Pitch** category.
You can assign gestures to:

- toggle processing;
- report whether processing is enabled and announce the current pitch;
- increase or decrease the current voice's Sonic pitch by 5;
- reset the current voice's Sonic pitch to 50;
- open the author's support page.

No gestures are assigned by default. The meaning of a step of 5 depends on
the selected pitch range.

## Troubleshooting

### Sonic pitch is missing

Enable **Enable global Sonic pitch**, save the settings and reopen Voice
settings. If needed, switch to another synthesizer and back, or restart NVDA.

### Changing the value has no effect

Check that processing is enabled and the value differs from 50. Your
synthesizer must use a supported audio output. With SAPI4, the older audio
output bypasses this add-on. The higher-quality option has no pitch-changing
effect on its own when Sonic pitch is neutral.

### The value changes after selecting another voice

Each voice or supported variant can have a different saved value. Adjust
Sonic pitch for the newly selected voice if necessary.

### A SAPI voice is missing from NVDA

Install and configure the voice using its own tools, then restart NVDA.
Global Sonic Pitch does not add or repair entries in the SAPI voice list.

### Reporting a problem

Enable debug logging, reproduce the problem and use NVDA's log viewer to
collect relevant entries. Include the NVDA version and architecture, add-on
version, synthesizer and voice, pitch value, range and quality mode, and the
steps needed to reproduce the issue. Review logs for private text before sharing.
Report problems in the [issue tracker](https://github.com/djgraco/sonicpitch/issues).
